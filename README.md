# 🧠 Formação em Machine Learning e Ciência de Dados - SCTI.SC

Bem-vindo(a) ao repositório oficial do curso de **Lógica de Programação e Machine Learning** do SCTI/SENAI! 

Este espaço foi criado para centralizar todos os códigos, notebooks, exercícios e materiais práticos desenvolvidos durante as aulas. Nossa jornada vai do básico da programação em Python até a criação, avaliação e deploy de modelos de Inteligência Artificial.

---

## 🎯 Objetivo do Repositório
Fornecer um ambiente de consulta e prática para os alunos. Aqui você encontrará os *scripts* passo a passo, anotações de aula e os laboratórios práticos ("Mão na Massa").

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Python 3
* **Ambientes:** Google Colab e Visual Studio Code (VS Code)
* **Controle de Versão:** Git e GitHub
* **Manipulação de Dados:** NumPy e Pandas
* **Visualização:** Matplotlib e Seaborn
* **Machine Learning:** Scikit-Learn

---

## 📚 Estrutura do Curso (Ementa Completa)

### 📌 Módulo 1: Fundamentos de Programação para Dados
* **Semana 1:** Introdução à área de Dados, IA e Lógica Computacional.
* **Semana 2:** Arquitetura básica, fluxogramas e primeiros passos no código.
* **Semana 3:** O idioma da IA (Tipos primitivos, Operadores, Estruturas de Decisão `if/else` e Repetição `for/while`).
* **Semana 4:** Controle de Versão com Git, GitHub e configuração do ambiente local no VS Code.
* **Semana 5:** Matemática para IA: Introdução ao **NumPy** (Arrays e Matrizes).
* **Semana 6:** O "Excel" do Python: Manipulação e Limpeza de Dados com **Pandas** (DataFrames e Series).
* **Semana 7:** Visualização de Dados e Storytelling: Gráficos com **Matplotlib** e **Seaborn**.
* **Semana 8:** Introdução ao Machine Learning e Pré-processamento de Dados (Feature Engineering).
* **Semana 9:** Treinando a Máquina: Algoritmos de Regressão e Classificação (**Scikit-Learn**).
* **Semana 10:** Avaliação de Modelos: Métricas de erro, matriz de confusão e o desafio do Overfitting vs Underfitting.
* **Semana 11:** Desenvolvimento do Projeto Final (Pipeline End-to-End).
* **Semana 12:** Apresentação de Resultados e próximos passos na carreira de Dados.
